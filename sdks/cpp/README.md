# C++ API client

Unofficial documentation of the reverse-engineered API behind the GSPNS (JGSP \"Novi Sad\")
public transport network — the same API used by the **NSmart** mobile app
(`buslogic.nsmartapp`).

The API is served by **BusLogic/NSmart** (`online.nsmart.rs`) and provides:

* the static transport network (cities → stations → line pairs),
* real-time vehicle positions and arrival predictions per station,
* electronic ticketing / wallet / card management endpoints (login, e-wallet, top-up…).

## Reverse engineering provenance

* Endpoint paths, class names and the shared API key were recovered from the
  NSmart 4.6 Android APK (see [FmasterofU/NSmart-RE](https://github.com/FmasterofU/NSmart-RE)).
* Response schemas below were verified against the live API in September 2026.
* The API key (`4670f468049bbee2260`) is compiled into the public APK as
  `company_api_key` and is the same for every install — treat it as public knowledge.

All endpoints in this document include that header in their `security` requirements.

## Notes & quirks (learned the hard way)

* The giant network payload (`networkextended.php`) is **not valid JSON when served
  over a slow connection** — the server truncates / corrupts the stream mid-body
  (raw control characters, null-byte runs, dropped chunks). The NSmart app
  apparently tolerates this; re-request until you get a parseable body.
* `networkextended.php` ignores semantically different `action` values
  (`get_network`, `get_trips`, `get_schedule` return the same cities payload as
  `get_cities_extended`).
* `announcement.php` returns `[{\"success\":false,\"code\":3}]` for an unknown
  `station_uid`. For a *known* station with nothing due it returns a single
  placeholder entry (`{\"just_coordinates\":\"1\", ...}`) instead of an empty array.
* A vehicle without a GPS fix is reported at `lat: \"0.00000000\"`, `lng: \"0.00000000\"`
  (often with an empty `garageNo`) — treat `0,0` as \"position unknown\".
* `networkextended.php` also answers a plain `GET` with no parameters, and the payload
  holds far more than `cities`: the flat `stations` and `lines` lists are what most
  clients want (see the `Network` schema and `docs/data-notes.md`).
* Timetables (scheduled departures) are **not** served by this API — see
  `docs/timetables.md` for the official gspns.co.rs pages that carry them.
* `ibfm=TM00000` means \"all lines\"; pass a line code (e.g. `7A`) to filter.
* Serbian text is `UTF-8`; strings may come back with JS-style unicode escapes.

## Installation

### Prerequisites

Install [cpprestsdk](https://github.com/Microsoft/cpprestsdk).

- Windows: `vcpkg install cpprestsdk cpprestsdk:x64-windows boost-uuid boost-uuid:x64-windows`
- Mac: `brew install cpprestsdk`
- Linux: `sudo apt-get install libcpprest-dev`

### Build

```sh
cmake -DCPPREST_ROOT=/usr -DCMAKE_CXX_FLAGS="-I/usr/local/opt/openssl/include" -DCMAKE_MODULE_LINKER_FLAGS="-L/usr/local/opt/openssl/lib"
make
```

### Build on Windows with Visual Studio (VS2017)

- Right click on folder containing source code
- Select 'Open in visual studio'
- Once visual studio opens, CMake should show up in top menu bar.
- Select CMake > Build All.

*Note: If the CMake menu item doesn't show up in Visual Studio, CMake
for Visual Studio must be installed. In this case, open the 'Visual Studio
Installer' application. Select 'modify' Visual Studio 2017. Make sure
'Desktop Development with C++' is installed, and specifically that 'Visual
C++ tools for CMake' is selected in the 'Installation Details' section.

Also be sure to review the CMakeLists.txt file. Edits are likely required.*
